# VPN 与机场有什么区别：按交付方式选择

[返回选购指南](../README.md)

“机场”是中文用户对部分代理订阅服务的俗称，不能仅凭名字判断其协议或经营情况。商业 VPN 与代理订阅在实际使用上经常有以下差异，但具体服务必须逐项核对。

| 比较项 | 商业 VPN 常见形式 | 代理订阅常见形式 |
| --- | --- | --- |
| 开始使用 | 安装服务商应用，登录账号 | 获得订阅地址，导入兼容客户端 |
| 设备支持 | 看官方应用和支持列表 | 同时看协议、客户端、系统版本 |
| 计费 | 按周期、设备或功能 | 按周期、流量、线路等组合 |
| 配置维护 | 应用通常管理连接配置 | 订阅更新与客户端规则需分别检查 |
| 判断隐私 | 阅读日志政策及审计范围 | 同样需要政策和可核实证据 |

这些是核查方向，不能当作每家服务的事实。例如部分代理服务也有自己的应用，部分 VPN 也有手动配置方式。

## 第一步：确认你要解决的问题

只需要一个应用方便连接，优先核对官方应用是否支持你的设备。需要按应用或网站选择连接方式，查看具体客户端的规则功能。需要路由器连接，先确认型号与固件支持，不要买完套餐才发现无法安装。

## 第二步：检查隐私边界

连接经过第三方服务意味着增加了一个需要信任的服务方。加密连接不等于所有使用过程匿名。账户、付款、浏览器登录、应用权限以及服务端日志仍需要分别考虑。

“无日志”口号需要对照政策原文。审计报告也要看日期、对象和范围：应用审计不能自动替代服务器日志政策审计。

## 第三步：实际验证后决定付款周期

先确认可用设备和目标服务，再用自己的网络测试。无法验证的情况保持“未知”，不要用论坛上一次成功经历推断长期可用。初次购买前读退款条款；如果没有明确退款机制，把付款当作可能无法追回的支出。
