# 搜索内容与运营计划

## 当前覆盖的搜索问题

| 页面 | 主问题 | 独立价值 |
| --- | --- | --- |
| README | VPN 与机场怎么选 | 用途分流、费用示例与入口 |
| vpn-vs-proxy | VPN 和机场有什么区别 | 交付方式与决策步骤 |

| testing-methodology | VPN 速度怎么测试 | 环境、基线、样本与结论边界 |

这些是内容目标，不是已经验证的关键词搜索量或排名结果。候选名录不应拆成 44 个只有名称与链接的空页面。

## 下一步工作顺序

1. 接入维护者自己的联盟链接，核对最终品牌与佣金归因。
2. 选择少量服务商逐项查官方套餐、退款、客户端和隐私资料。
3. 取得自己的使用记录，补充有日期的比较和优缺点。
4. 有足够证据后建立独立服务商页面，相互链接并持续纠错。
5. 观察 Google 是否收录公开仓库页面；GitHub 上无法由维护者设置独立页面的所有搜索标签，也不能凭创建仓库断言收录。
6. 如需长期经营独立联盟网站，评估独立域名和合适的托管服务；本项目未启用 GitHub Pages。

不要堆砌品牌名称、伪造使用经历或承诺谷歌排名与收入。依据 Google 的[评论指南](https://developers.google.com/search/docs/specialty/ecommerce/write-high-quality-reviews)与[联盟内容建议](https://developers.google.com/search/blog/2014/01/affiliate-programs-and-added-value)补充真实增量价值。独立网站的付费链接应按[官方说明](https://developers.google.com/search/blog/2021/07/link-tagging-and-link-spam-update)标记。

GitHub Pages 的商业使用边界应参考[官方限制](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)。不要把公开仓库完成等同于商业网站已部署。
