# Windows、Mac、iPhone、Android 的 VPN 客户端怎么选

[返回选购指南](../README.md)

先区分官方应用与通用订阅客户端。服务商支持一种协议，不代表任何客户端都能读取其全部配置。

| 设备 | 购买前检查 | 首次验证 |
| --- | --- | --- |
| Windows | 最低系统版本、安装来源、管理员权限要求 | 安装、连接、断开、退出后网络恢复 |
| Mac | 系统版本、芯片支持、所需权限 | 睡眠唤醒与网络切换后连接表现 |
| iPhone / iPad | 商店地区、系统要求、应用是否另收费 | Wi-Fi 与移动网络切换 |
| Android | 官方下载来源、系统兼容、后台限制 | 锁屏后运行与电池消耗 |
| 路由器 | 精确型号、固件、硬件性能、恢复方式 | 小范围测试后再覆盖全部设备 |

## 不要只看客户端名称

记录具体版本、来源和服务商官方配置说明。第三方教程可能针对旧版本；名称相似的下载站也不能代替官方来源。商业 VPN 优先使用服务商正式支持的应用；代理订阅以服务商兼容说明为起点。

## 订阅地址需要保护

订阅地址可能包含访问凭证。不要贴到公开 Issue、截图、仓库或在线配置转换工具。求助时提供经过遮盖的错误信息、客户端版本和设备型号。

## 连接成功之后还要检查

打开你实际使用的办公或影音应用；检查断开连接后网络能否正常恢复。按需观察耗电、切换网络与睡眠唤醒表现。全局连接与按应用分流有不同作用，设置前应理解当前客户端的说明。

如果连接失败，依次确认账户有效、配额足够、设备时间正确、配置为最新版本，并记录错误信息再联系官方支持。不要通过关闭安全软件或安装不明证书来碰运气。
